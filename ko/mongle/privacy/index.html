Windows용 몽글

Microsoft Store 버전은 성격 테스트, 친구 코드 비교, 도감 진행 처리를 이 PC에서 수행합니다. 광고·분석 SDK가 없으며 해당 기록을 개발자 서버로 보내지 않습니다. 문항 답변과 진행 상황, 결과, 별명, 친구 기록, 설정과 도감은 앱의 로컬 데이터 폴더에 저장됩니다. 언어 선택은 현재 Windows 사용자의 환경설정에도 저장됩니다.

카메라는 QR 스캔을 선택하고 카메라 안내에 동의한 뒤에만 시작합니다. 영상은 몽글 친구 코드를 읽기 위해 PC 안에서 처리하며 녹화하거나 업로드하지 않습니다. 스캔이 끝나거나 취소하면 카메라를 닫습니다. 카메라 없이 친구 코드를 직접 입력할 수도 있습니다.

카드를 저장하면 Windows 사진 위치의 Mongle 폴더에 PNG 파일을 만듭니다. 사진 위치는 Windows 또는 OneDrive 설정에 따라 다른 폴더로 연결되거나 동기화될 수 있습니다. 공유는 직접 요청할 때만 Windows 공유 창을 엽니다. 선택한 내용을 전달하기 위해 임시 카드·요청 파일을 사용하며 공유 도우미가 정상 종료되면 삭제합니다. 이후 처리는 Windows, 받는 앱과 선택한 대상의 정책을 따릅니다. 백업 복사·가져오기는 클립보드를 사용하며 클립보드 기록·동기화는 Windows 설정을 따릅니다.

설정에서 앱 기록을 초기화할 수 있습니다. 내보낸 JSON, 저장한 이미지와 외부 백업은 따로 삭제해야 합니다. 앱을 제거해도 로컬 데이터·환경설정·내보낸 파일이 남을 수 있습니다. 개인정보처리방침을 열면 브라우저가 실행되며 웹사이트의 처리는 아래 안내를 따릅니다. 이메일 문의 시 보낸 주소와 내용은 답변에 사용하므로 민감한 기록은 포함하지 마세요. Windows 안내 수정일: 2026-10-23.

몽글 앱은 계정·광고·분석 서버 없이 동작하며 개발자에게 개인정보를 수집하거나 전송하지 않습니다. 테스트 결과, 별명, 친구 목록, 설정과 도감 진행 상황은 기기에 저장됩니다.

카메라는 사용자가 요청한 QR 코드 스캔에만 사용합니다. 영상은 저장하거나 전송하지 않습니다. 사진 추가 권한은 결과 카드를 사진 앱에 저장할 때만 사용합니다.

친구 코드, 카드 이미지, JSON 백업은 사용자가 직접 공유할 때 선택한 앱으로 전달됩니다. 이메일 문의를 보내면 주소와 문의 내용이 지원 업무에 사용됩니다. 민감한 정보는 보내지 마세요.

앱 설정에서 모든 데이터를 초기화하거나 앱을 삭제할 수 있습니다. 별도로 내보낸 파일과 사진은 사용자가 삭제해야 합니다. 운영체제의 기기 백업 설정에 따라 앱 데이터가 백업될 수 있습니다.

웹사이트는 쿠키 없는 방문 집계와, 동의한 경우에만 Google Analytics를 사용합니다. 웹사이트 통계는 Windows 앱의 로컬 기록과 별개입니다. 처리 내용과 선택 방법은 웹사이트 통계 안내에서 확인할 수 있습니다. GitHub Pages는 웹페이지 제공과 보안을 위해 IP 주소 등 접속 정보를 처리할 수 있습니다.
