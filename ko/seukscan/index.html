FAQ

자주 묻는 질문

스캔한 문서가 서버로 전송되나요?

문서 스캔과 문자 인식은 기기에서 처리됩니다. H1Soft는 문서나 인식한 텍스트를 서버로 수집하지 않습니다. 공유·내보내기·백업을 선택하면 사용자가 고른 앱이나 저장 위치로 파일이 전달됩니다. 문자 인식은 기기와 문서 언어에 따라 달라집니다.

어떤 형식으로 내보낼 수 있나요?

PDF, JPG, PNG, 텍스트 파일로 내보내세요. PDF 용지 크기와 품질을 고르고 열람 비밀번호와 워터마크를 추가할 수 있습니다.

신분증도 스캔할 수 있나요?

신분증·여권 규격 스캔과 책 펼침면 분할을 지원합니다. 폴더와 즐겨찾기로 정리하고 여러 문서를 하나로 병합하세요.

여러 페이지 문서도 스캔되나요?

페이지를 추가하고 크롭·필터·회전으로 한 문서를 다듬으세요.

문의는 어디로 하나요?

문의나 오류 제보는 아래 이메일로 보내주세요. 기기 모델과 iOS 버전을 적어주시면 도움이 됩니다. 민감한 문서 원본은 보내지 마세요.
