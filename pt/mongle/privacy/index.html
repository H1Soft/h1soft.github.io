Mongle · Privacidade

O Mongle funciona sem conta nem servidores de publicidade ou análise. O desenvolvedor não coleta nem recebe dados pessoais do app. Resultados, apelidos, amigos, configurações e progresso ficam no dispositivo.

A câmera é usada apenas para ler o QR de um amigo. Nenhum vídeo é salvo ou enviado. A permissão para adicionar fotos serve apenas para salvar um cartão no app Fotos.

Códigos, imagens e backups JSON são enviados ao app escolhido somente quando você os compartilha. Ao escrever para o suporte, seu endereço e mensagem são usados para responder. Não envie informações sensíveis.

Redefina os dados nas configurações ou exclua o app. Exclua arquivos exportados e fotos salvas separadamente. O sistema pode incluir dados do app nos backups do dispositivo conforme suas configurações.

Este site não usa scripts de publicidade ou análise. O GitHub Pages pode processar endereços IP e dados de conexão para fornecer e proteger o site. Consulte a declaração de privacidade do GitHub.
