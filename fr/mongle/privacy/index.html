Confidentialité

Mongle fonctionne sans compte ni serveur publicitaire ou d’analyse. Le développeur ne collecte ni ne reçoit de données personnelles de l’app. Résultats, surnoms, amis, réglages et progression restent sur votre appareil.

La caméra sert uniquement à scanner le code QR d’un ami. Aucune vidéo n’est enregistrée ni envoyée. L’autorisation d’ajouter des photos sert uniquement à enregistrer une carte dans Photos.

Les codes, images et sauvegardes JSON sont transmis à l’app choisie uniquement si vous les partagez. Si vous contactez l’assistance par e-mail, votre adresse et votre message servent à vous répondre. N’envoyez pas de données sensibles.

Réinitialisez vos données dans les réglages ou supprimez l’app. Supprimez séparément les fichiers exportés et les photos enregistrées. Le système peut inclure les données dans les sauvegardes de l’appareil selon vos réglages.

Ce site ne contient aucun script publicitaire ou d’analyse. GitHub Pages peut traiter l’adresse IP et les informations de connexion pour fournir et protéger le site. Consultez la déclaration de confidentialité de GitHub.

L’app est un divertissement, pas une évaluation psychologique professionnelle. Contact : kvlksgjp1@gmail.com. Mise à jour : 2026-09-07.
