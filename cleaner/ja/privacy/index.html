01

適用範囲と運営者

本ポリシーは、H1Soft が運営する Phone Cleaner Android アプリ およびその 製品ウェブサイトに適用されます。端末内でのファイル処理、ウェブサイトの閲覧、サポートメールを区別して説明します。

運営者およびプライバシーに関するお問い合わせ先： H1Soft
メール： h1.soft.x001@gmail.com

02

アプリ内で処理する情報

アカウントは不要です。現在の Android 版にはインターネット権限がなく、写真、動画、アプリの利用情報を H1Soft のサーバーに送信しません。広告、行動分析、リモートでのクラッシュ報告を行う SDK は含まれていません。

  • メディア： アクセスを許可した写真、動画、音声、サムネイル、ファイル名とパス、ファイルサイズ、形式、撮影日時と更新日時、画像の縦横サイズ、再生時間を処理します。ファイルの比較、ストレージの確認、プレビュー、容量を小さくする処理に使用します。
  • 分析： 比較用ハッシュ、類似度、ぼけや明るさの情報、残すものとして選択した内容を端末内に保存します。個人の識別には使用しません。
  • アプリとストレージ： アプリ名、パッケージ、アイコン、最終利用日時、アプリのサイズ、ストレージの空き容量を使い、開いていないアプリを見つけます。
  • 設定と履歴： 言語、テーマ、容量を小さくする際のプリセット、処理状況、整理した項目、ストレージの結果をアプリ専用の保存領域に保管します。

チャットメディアのツールは、端末内の共有メディアファイルを確認します。メッセージアカウントへのログインや、非公開の会話の読み取りは行いません。連絡先、通話履歴、端末の位置情報へのアクセスも要求しません。

03

権限と利用者の選択

写真と動画

許可されたメディアの分析とプレビューに使用します。アクセスを制限すると、結果も制限されます。

音声

対応する整理ツールで音声を確認するために使用します。マイクを使った録音は行いません。

使用状況へのアクセス

アプリの利用日時と使用容量を確認するために使用します。

通知とメディア管理

通知では、進行状況やストレージに関するお知らせを表示します。任意のクイック整理権限を許可すると、システムの確認手順が簡略化されます。選択した操作だけを実行します。

Android の設定で権限を拒否または取り消すことができます。その権限を必要とする機能は制限されますが、ほかの機能は引き続き利用できます。アクセス権限を取り消しても、すでに端末内に保存された記録が消去されるわけではありません。

04

端末内での保管と削除

  • インデックス、設定、履歴： 機能の提供と結果の再利用のために端末内で保管します。アプリ専用データを削除するには、Android のストレージ設定でアプリのデータを消去するか、アプリをアンインストールしてください。サムネイルや一時キャッシュは、処理後の整理や OS によるキャッシュ管理の際にも消去されることがあります。
  • 元のファイルと容量を小さくしたファイル： 端末のメディアライブラリに保存します。アプリのデータを消去したり、Phone Cleaner をアンインストールしたりしても、これらのファイルは削除されません。
  • ゴミ箱： 移動したメディアは、表示される保管期間にわたり Android のシステムのゴミ箱で管理されます。本アプリの保管期間は30日です。完全に削除した場合や期限が切れた場合は、復元できなくなります。残りの期間はゴミ箱で確認してください。
  • バックアップと同期： Android のバックアップ、端末間のデータ移行、写真ライブラリの同期により、設定および各提供事業者のポリシーに従って、別のコピーが作成される場合があります。これらはプラットフォームや写真サービスの機能であり、Phone Cleaner が運営するアップロードサービスではありません。

05

ウェブサイトの閲覧

この製品ウェブサイトには、登録、決済、ファイルのアップロード機能はありません。H1Soft は広告トラッカー、訪問者分析、トラッキング Cookie を追加していません。Phone Cleaner のページで使うフォントと画像は、同じウェブサイトから配信しています。

ホスティング事業者の GitHub は、セキュリティのために訪問者の IP アドレスを記録・保存すると説明しています。これらのアクセス記録は、アプリ内で分析するメディアや整理履歴とは別のものです。処理と保管の詳細は、 GitHub Pages のデータ収集 および GitHub のプライバシーに関する声明 をご覧ください。

サポートのやり取りは、 お問い合わせの解決後、最長1年間保管し、その後削除します。それより早い削除を求めることもできます。法令で保管が義務付けられている場合や、継続中の紛争のために保管が必要な場合は、その理由と必要な期間に限定して保管します。メールと添付ファイルは、保管目的がなくなった時点で削除します。

07

サービス提供事業者と国外での処理

H1Soft は、アプリ内のメディア、分析結果、利用情報を販売したり、広告目的で提供したりしません。端末内での分析を外部に委託することもありません。

  • GitHub, Inc.： ウェブサイトのホスティングと、セキュリティのためのアクセス記録を扱います。
  • Google Gmail： サポート宛てに送信されたメールと添付ファイルの配信・保存を行います。

これらの事業者は、米国など、お住まいの国以外の国で情報を処理する場合があります。所在地、保管の取り扱い、権利行使の手続きについては、GitHub のプライバシーに関する声明および Google のプライバシーポリシーに記載されています。メールを送信しなければ、サポート用の資料は送信されません。ウェブサイトの閲覧やサポートへのメール送信をせずに、アプリの端末内の機能を利用できます。

適法な請求により開示が求められる場合は、適用される法令の範囲と手続きに従います。

08

プライバシーに関する権利

H1Soft が保有するサポートデータの開示、訂正、削除、または利用制限を求める場合は、 h1.soft.x001@gmail.com にご連絡ください。法定代理人や権限を与えられた代理人が代わりに手続きを行うこともできます。権限の確認に必要な情報のみを求め、請求に法的な制限がある場合は、その内容を説明します。

H1Soft は、利用者の端末内だけに保存されているメディアや分析記録に、遠隔でアクセスしたり、それらを消去したりすることはできません。メディアは端末のライブラリとゴミ箱で、アプリ専用の記録は Android のアプリ設定で管理してください。閉鎖が必要なアカウントはありません。

09

情報の保護と子どもの利用

端末内の分析情報は、Android のアプリ専用の保存領域と権限制御を用いて管理します。ウェブサイトは HTTPS を使用しています。サポート情報は、回答に必要な範囲でのみ取り扱います。端末のロック、OS の更新、バックアップ設定も、情報の保護に役立ちます。

14歳未満の子どもと知りながら個人情報を収集することはありません。子どもがサポートに連絡する際は、事前に保護者の助けを得てください。子どもの情報が送信されたと判明した場合は、法令で必要とされる保護者の確認や同意を得るか、不要な情報を削除します。
