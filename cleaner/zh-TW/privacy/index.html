01

適用範圍與營運者

本政策適用於由 H1Soft 營運的 Phone Cleaner Android 應用程式 及其 產品網站，並分別說明裝置端檔案處理、網站瀏覽及支援郵件的相關事項。

營運者與隱私權聯絡窗口： H1Soft
電子郵件： h1.soft.x001@gmail.com

02

應用程式內處理的資訊

不需要帳號。目前的 Android 版本沒有網際網路存取權限，不會將照片、影片或應用程式使用資訊傳送至 H1Soft 伺服器。應用程式不含廣告、行為分析或遠端當機回報 SDK。

  • 媒體： 經你允許存取的照片、影片、音訊、縮圖、檔案名稱與路徑、檔案大小、格式、拍攝與修改時間、尺寸及播放長度。這些資訊用於檔案比較、儲存空間檢視、預覽及縮小檔案容量。
  • 分析： 用於比較的雜湊值、相似度、模糊與亮度資訊，以及你選擇保留的項目，都儲存在裝置上，不用於識別個人身分。
  • 應用程式與儲存空間： 應用程式名稱、套件、圖示、上次使用時間、應用程式大小及可用儲存空間，可協助找出你未開啟的應用程式。
  • 設定與歷史紀錄： 語言、佈景主題、縮小容量的預設組態、作業狀態、已清理項目及儲存空間結果，保存在應用程式專用儲存空間內。

聊天媒體工具會檢查裝置上的共用媒體檔案，不會登入通訊帳號，也不會讀取私人對話。應用程式不會要求存取聯絡人、通話紀錄或裝置位置。

03

權限與你的選擇

照片與影片

用於分析及預覽你允許存取的媒體。存取範圍受限時，結果範圍也會受到限制。

音訊

用於在對應的清理工具中檢視音訊，不會透過麥克風錄音。

使用情況存取權限

用於查看應用程式使用時間與佔用的儲存空間。

通知與媒體管理

通知會顯示進度與儲存空間提醒。可自行選擇是否授予快速整理權限，以簡化系統確認流程。只會執行你選取的操作。

你可以在 Android 設定中拒絕或撤銷權限。需要這些權限的功能會受到限制，其他功能仍可使用。撤銷存取權限本身不會清除先前儲存的本機紀錄。

04

本機保留與刪除

  • 索引、設定與歷史紀錄： 保留在本機，用於提供功能及重複使用結果。若要移除應用程式專用資料，請在 Android 儲存空間設定中清除應用程式資料，或解除安裝應用程式。縮圖與暫存快取也可能在作業收尾清理或作業系統快取管理時清除。
  • 原始檔案與縮小容量後的檔案： 儲存在裝置的媒體庫中。清除應用程式資料或解除安裝 Phone Cleaner，不會一併刪除這些檔案。
  • 垃圾桶： 移入的媒體由 Android 系統垃圾桶依其顯示的保留期限管理。本應用程式採用 30 天的保留期間；永久刪除或期限屆滿後，即無法還原。請在垃圾桶查看剩餘時間。
  • 備份與同步： Android 備份、裝置移轉或照片圖庫同步，可能依你的設定及相關供應商的政策建立獨立副本。這些是平台或照片服務的功能，並非由 Phone Cleaner 營運的上傳服務。

05

網站瀏覽

本產品網站沒有註冊、付款或檔案上傳功能。H1Soft 未加入廣告追蹤工具、訪客分析工具或追蹤 Cookie。Phone Cleaner 頁面使用的字型與圖片均由同一網站提供。

我們的網站託管服務供應商 GitHub 表示，會基於安全目的記錄並儲存訪客的 IP 位址。這些存取紀錄與應用程式內分析的媒體或清理歷史紀錄分開處理。關於處理與保留的詳細資訊，請參閱 GitHub Pages 資料蒐集說明 以及 GitHub 隱私權聲明 中的相關說明。

06

支援郵件與保留期限

如果你寄送電子郵件至 h1.soft.x001@gmail.com，我們會收到你的電子郵件地址、信件內容，以及你選擇寄送的附件。我們僅將這些資料用於回覆並調查你的問題。請提供必要的說明及應用程式和裝置版本，而非原始照片或敏感文件。

支援服務往來信件的保留期限為 詢問事項解決後最多一年，之後即予刪除。你可以要求提早刪除。若法律要求保留，或處理持續中的爭議需要保留，我們會將保留限於該事由與必要期間。保留目的結束後，電子郵件與附件即會刪除。

07

服務供應商與跨境處理

H1Soft 不會出售應用程式內的媒體、分析結果或使用資訊，也不會提供作為廣告用途。裝置端分析不會委外處理。

  • GitHub, Inc.： 提供網站託管，並處理用於安全目的的存取紀錄。
  • Google Gmail： 負責傳遞及儲存你寄給支援團隊的電子郵件與附件。

這些供應商可能在美國及你居住國以外的其他國家處理資訊。其所在地、資料保留方式及權利行使程序，請參閱 GitHub 隱私權聲明與 Google 隱私權政策。如果你未寄送電子郵件，就不會傳送任何支援資料。即使不瀏覽網站或寄信給支援團隊，也能使用應用程式的本機功能。

如合法請求要求揭露資訊，我們會遵循適用的法律限制與程序。

08

你的隱私權利

你可以聯絡 h1.soft.x001@gmail.com ，要求查閱、更正、刪除 H1Soft 持有的支援資料，或限制其處理。法定監護人或經授權的代理人可以代為提出要求。我們只會要求提供確認權限所需的資訊，並說明該要求受到的任何法律限制。

H1Soft 無法遠端存取或清除僅儲存在你裝置上的媒體或分析紀錄。請透過裝置媒體庫與垃圾桶管理媒體，並透過 Android 應用程式設定管理應用程式專用紀錄。沒有需要關閉的帳號。

09

資訊保護與兒童

本機分析資訊透過 Android 的應用程式專用儲存空間與權限控管進行管理。網站使用 HTTPS。支援資訊只在回覆所需的範圍內處理。裝置鎖定、作業系統更新與備份設定，也有助於保護你的資訊。

我們不會在知情的情況下蒐集未滿 14 歲兒童的個人資料。兒童聯絡支援團隊前，應先請監護人協助。如果我們得知有人提交兒童資料，會依法取得必要的監護人確認或同意，或刪除不必要的資料。
