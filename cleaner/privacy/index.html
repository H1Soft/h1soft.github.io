01

적용 범위와 운영자

이 방침은 H1Soft가 제공하는 폰 클리너 Android 앱과 폰 클리너 소개 홈페이지에 적용돼요. 앱의 파일 처리, 홈페이지 접속, 이메일 문의를 구분해 안내해요.

운영자 및 개인정보 문의 담당: H1Soft
연락처: h1.soft.x001@gmail.com

02

앱에서 처리하는 정보

폰 클리너는 회원가입 없이 사용해요. 현재 Android 배포용 앱에는 인터넷 권한이 없으며, 사진·동영상·앱 사용 정보를 H1Soft 서버로 전송하지 않아요. 광고, 행동 분석, 원격 오류 수집용 SDK를 포함하지 않아요.

  • 미디어 정보: 허용한 사진·동영상·오디오, 썸네일, 파일 이름과 경로, 크기, 형식, 촬영·수정 시각, 해상도, 재생 시간 등을 읽어요. 중복·유사 사진 비교, 용량 확인, 미리보기와 줄이기에 사용해요.
  • 분석 결과: 파일 비교용 해시, 유사도, 흐림·밝기 정보, 보존 선택을 기기에 저장해요. 사람의 신원을 식별하는 용도로 사용하지 않아요.
  • 앱과 저장 공간: 안 쓰는 앱을 살펴보기 위해 앱 이름·패키지·아이콘, 마지막 사용 시각, 앱별 크기와 기기 여유 공간을 확인해요.
  • 설정과 기록: 언어, 테마, 줄이기 설정, 작업 진행 상태, 정리한 항목과 용량을 앱 전용 저장소에 보관해요.

메시지 미디어 기능은 기기의 공유 미디어 파일을 살펴봐요. 메신저 계정에 로그인하거나 비공개 대화 내용을 읽는 기능이 아니에요. 앱은 연락처·통화 기록·위치 접근 권한을 요청하지 않아요.

03

권한과 선택권

사진·동영상

허용한 범위에서 파일을 분석하고 미리 보여줘요. 제한된 접근을 선택하면 결과도 해당 범위로 제한돼요.

오디오

관련 정리 도구에서 오디오 파일을 확인할 때 사용해요. 마이크로 소리를 녹음하지 않아요.

사용 정보 접근

안 쓰는 앱의 사용 시각과 용량을 확인할 때 사용해요.

알림·미디어 관리

알림은 진행 상태와 저장 공간 안내에, 선택적인 빠른 정리 권한은 시스템 확인 절차 간소화에 사용해요. 사용자가 선택한 작업만 실행해요.

Android 설정에서 권한을 거부하거나 철회할 수 있어요. 권한이 필요한 기능은 제한되지만 다른 기능은 사용할 수 있어요. 권한 철회는 이미 저장된 앱 내부 기록을 자동으로 삭제하는 동작과는 달라요.

04

기기 안의 보관과 삭제

  • 분석 색인·설정·정리 기록: 기능 제공과 재사용을 위해 기기 안에 보관해요. Android의 앱 저장 공간에서 데이터를 삭제하거나 앱을 제거하면 해당 앱 전용 데이터가 삭제돼요. 썸네일·임시 파일 캐시는 작업 정리 또는 운영체제의 캐시 관리 과정에서도 지워질 수 있어요.
  • 원본·줄인 파일: 기기의 사진·동영상 보관함에 저장돼요. 앱 데이터 삭제나 앱 제거만으로 이 파일들이 함께 삭제되지는 않아요.
  • 휴지통: 옮긴 미디어는 Android 시스템 휴지통에서 표시된 보관 기간 동안 관리돼요. 앱은 30일 보관을 기준으로 안내하며, 직접 영구 삭제하거나 보관 기간이 끝나면 복원할 수 없어요. 남은 기간은 휴지통에서 확인해 주세요.
  • 백업·동기화: 사용자의 Android 백업, 기기 이전 또는 사진 앱 동기화 설정에 따라 데이터가 별도로 복사될 수 있어요. 해당 기능은 운영체제·사진 서비스의 설정과 정책을 따르며, 폰 클리너의 서버 전송 기능이 아니에요.

05

홈페이지 접속 정보

이 소개 홈페이지에는 회원가입·결제·파일 업로드 기능이 없어요. H1Soft가 추가한 광고 추적기, 방문 분석 도구 또는 추적 쿠키도 없어요. 폰 클리너 페이지의 글꼴과 이미지는 같은 홈페이지에서 제공해요.

호스팅 사업자인 GitHub는 보안을 위해 방문자의 IP 주소를 기록하고 저장한다고 안내해요. 이 접속 기록은 앱이 분석한 사진이나 정리 기록과는 별개예요. 처리와 보관 기준은 GitHub Pages 안내와 GitHub 개인정보처리방침에서 확인할 수 있어요.

문의 이메일과 보관 기간

h1.soft.x001@gmail.com로 직접 문의하면 발신 이메일 주소, 본문, 사용자가 첨부한 자료를 받게 돼요. 문의에 답하고 문제를 확인하는 목적으로만 이용해요. 사진 원본이나 민감한 문서 대신, 필요한 설명과 기기·앱 버전만 보내 주세요.

문의 기록은 응대 완료 후 최대 1년 보관한 뒤 삭제해요. 더 이른 삭제를 요청할 수 있어요. 법령상 보관 의무가 있거나 진행 중인 분쟁 대응에 꼭 필요한 경우에는 해당 사유와 필요한 기간에 한해 제한적으로 보관해요. 보관 목적이 끝난 자료는 이메일과 첨부파일을 삭제하는 방법으로 파기해요.

외부 서비스와 국외 처리

H1Soft는 앱의 미디어·분석 결과·사용 정보를 판매하거나 광고 목적으로 제공하지 않아요. 앱 내부 분석을 외부 업체에 맡기지 않아요.

  • GitHub, Inc.: 홈페이지 호스팅과 보안 접속 기록을 처리해요.
  • Google의 Gmail: 사용자가 보낸 문의 이메일과 첨부파일을 전달·보관하는 데 사용해요.

이 서비스들은 미국 등 이용자의 거주 국가 밖에서 정보를 처리할 수 있어요. GitHub의 개인정보처리방침과 Google 개인정보처리방침에서 각 사업자의 처리 지역, 보관 및 권리 행사 방법을 확인할 수 있어요. 사용자가 메일을 보내지 않으면 문의 자료는 전달되지 않아요. 앱의 기기 내 기능은 홈페이지 방문이나 이메일 문의 없이 사용할 수 있어요.

법령에 따른 적법한 요구로 정보를 제공해야 하는 경우에는 법령이 허용하는 범위와 절차를 따라요.
