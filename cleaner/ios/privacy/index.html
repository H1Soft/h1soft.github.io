적용 범위와 운영자

이 방침은 H1Soft의 폰 클리너 iPhone·iPad 앱과 관련 홈페이지·이메일 문의에 적용돼요. 개인정보 문의 담당은 H1Soft이며, h1.soft.x001@gmail.com으로 연락할 수 있어요.

앱에서 처리하는 정보

회원가입 없이 사용해요. 허용한 사진·동영상의 썸네일, 파일 이름, 크기, 형식, 촬영·수정 시각, 해상도와 재생 시간을 읽어 중복 비교, 미리보기와 줄이기에 사용해요. 비교용 해시, 유사도, 흐림·밝기 분석, 보존 선택, 언어·테마·줄이기 설정과 작업 기록은 앱 전용 저장소에 보관해요. 사람의 신원을 식별하는 데 사용하지 않아요. 사진과 분석 결과를 H1Soft 서버로 보내지 않으며 광고·행동 분석·원격 오류 수집 SDK를 포함하지 않아요.

사진 권한과 선택권

iOS 사진 접근 권한을 사용해요. 전체 접근 또는 선택한 사진만 허용할 수 있고, 제한된 접근에서는 결과도 해당 범위로 제한돼요. iOS 설정에서 권한을 철회하거나 변경할 수 있어요. 원본이 기기에 저장된 파일만 처리하며 iCloud에만 있는 원본은 자동으로 내려받지 않아요. 다른 앱의 사용 기록·메신저 비공개 데이터·연락처·마이크·위치 권한을 요청하지 않아요.

기기 안의 보관과 삭제

작은 사본은 사진 보관함에 저장하고 원본은 사용자가 삭제를 확인할 때까지 남겨요. 삭제하려면 직접 선택한 뒤 iOS 확인 창에서 승인해야 해요. 복원과 영구 삭제는 Apple 사진 앱의 ‘최근 삭제된 항목’에서 관리해 주세요. 폰 클리너는 해당 앨범을 직접 열람하거나 비우지 않아요. 앱을 삭제하면 앱 전용 설정·분석 기록이 제거되지만, 사진 보관함의 원본과 저장된 사본은 별도로 남아요. 기기 백업·이전·iCloud 사진 동기화는 Apple 설정과 정책을 따르며 폰 클리너의 서버 전송 기능이 아니에요.

홈페이지 접속 정보

소개 홈페이지에는 회원가입·결제·사진 업로드 기능이나 H1Soft가 추가한 광고 추적기·방문 분석 도구·추적 쿠키가 없어요. 호스팅 사업자인 GitHub는 보안을 위한 IP 주소 등의 접속 정보를 처리할 수 있어요. 이 접속 기록은 앱의 사진이나 정리 기록과 별개이며 GitHub 개인정보처리방침을 따라요.

문의 이메일과 보관 기간

이메일로 직접 문의하면 발신 주소, 본문과 사용자가 첨부한 자료를 받게 돼요. 문의 응대 목적으로만 사용하고, 응대 완료 후 최대 1년 보관한 뒤 삭제해요. 더 이른 삭제를 요청할 수 있어요. 법령상 의무나 진행 중인 분쟁 대응에 필요한 자료는 필요한 기간에 한해 보관해요. 민감한 사진 원본 대신 문제 설명과 앱·기기 버전을 보내 주세요.

외부 서비스와 국외 처리

홈페이지 호스팅에는 GitHub, 문의 이메일에는 Google Gmail을 사용해요. 해당 서비스는 미국 등 거주 국가 밖에서 정보를 처리할 수 있으며 각 사업자의 개인정보처리방침을 따라요. 앱의 미디어 분석을 외부 업체에 맡기거나 사진·분석 결과를 판매·광고 목적으로 제공하지 않아요. 법령에 따른 적법한 요구는 법령이 허용하는 절차와 범위에서 처리해요.
