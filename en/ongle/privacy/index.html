Ongle Privacy policy

2026-10-22 · Windows / Android / iOS

Windows edition

Ongle for Windows opens, edits, searches and converts HWP/HWPX documents selected by you on your computer. It does not automatically send documents or personal data to developer servers and uses no accounts, advertising, analytics or tracking SDKs.

Recent documents, reading positions, bookmarks, settings, preview and conversion caches, recovery drafts and saved signatures are stored locally. If you enable form autofill, the name, phone number, date of birth, email and address you enter are saved for that feature. App data is stored in H1Soft/Ongle under your Windows user local app data folder; the language choice also uses user preferences. Use the history, cache and profile controls to manage the corresponding data. Clearing the cache does not erase every setting, draft or signature.

PDF, image, table and text exports, original-file saves and backups create files at locations you choose. Manage exported files at those locations. Uninstalling the app may leave exported files and some local data behind. Deleting a portable app folder alone does not remove all user data.

Read aloud uses offline voices installed in Windows. If a voice for your chosen language is missing, the app explains this and does not automatically switch to a cloud speech service. Playback information and the document title may appear in Windows media controls.

Sharing, copying and opening external links start only when you choose those actions. Sharing uses the app you select in the Windows share interface; Ongle cannot confirm delivery. Optional issue reports contain the error description you review, document format and page count, and app, engine and operating-system details. The original document is included only when you choose to attach it. File providers, sharing destinations and Windows clipboard history, synchronization and backup follow their own policies and your settings.

Email addresses, message contents and optional attachments received for support are used to investigate and respond, then deleted when no longer needed. Contact h1.soft.x001@gmail.com. If processing changes, this policy and the Store declarations will be updated.

Android edition

The Android app has no internet permission and does not automatically send documents or personal data to developer servers. It has no accounts, advertising, analytics or tracking SDKs. User-selected documents are read and converted on the device.

Recent documents, access information, reading positions, bookmarks, settings, converted PDF/table/image files and preview caches are stored locally. Optional form autofill stores the name, phone number, birth date, email and address entered by the user locally for that feature. Use the available history/cache controls and profile editing, or clear app data, to manage local information. Exported files must be managed at their saved location.

Sharing, copying and opening external links happen at the user's request. An optional issue report previews the issue description, document format and page count, app/engine/OS versions and error details before handing them to a user-selected app. The original document is included only when the user opts to attach it. Transmission and file provider or receiving-service processing follow their policies.

Email addresses, messages and optional attachments received by support are used only for troubleshooting and responses, and deleted when no longer needed. Contact: h1.soft.x001@gmail.com. We update this policy and store disclosures if data practices change.

iOS privacy policy

The Ongle iOS app does not collect or transmit documents or personal data to developer servers. It has no accounts, analytics or tracking SDKs. Recent files, reading positions, settings and conversion results are stored on your device. You can clear recent history and cache in app settings. System backups and iCloud files follow your Apple settings and chosen file provider's policy. Sharing, copying and opening external links happen at your request and follow the receiving service's policy. Email enquiries disclose the sender address and message to support; we use them only to respond and delete them when no longer needed. We will update this policy and the store disclosures if data practices change.
