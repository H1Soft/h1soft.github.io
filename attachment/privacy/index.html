개인정보처리방침

애착인형 뽑기는 회원가입 없이 이용하는 자기 이해 콘텐츠예요. 이 방침은 H1Soft의 웹 서비스와 이 홍보 사이트에 적용돼요.

1. 기기에 저장하는 정보

테스트 결과, 닉네임, 모드, 인형 도감과 설정을 브라우저의 로컬 저장소에 보관할 수 있어요. 이름·전화번호·이메일을 입력하는 가입 절차는 없어요. 답변과 결과를 별도의 운영 서버로 전송해 저장하지 않아요.

2. 공유 링크

사용자가 공유를 선택하면 닉네임과 결과 점수가 링크에 포함될 수 있어요. 링크를 받은 사람은 해당 정보를 볼 수 있으므로 실명이나 민감한 내용을 닉네임에 넣지 않는 것을 권해요. 이미 다른 사람에게 전달한 링크는 기기에서 기록을 삭제해도 자동으로 회수되지 않아요.

3. 호스팅과 외부 연결

사이트는 GitHub Pages에서 제공돼요. GitHub는 서비스 제공과 보안을 위해 방문자의 IP 주소 등 접속 정보를 처리할 수 있어요. 자세한 내용은 GitHub 개인정보처리방침을 확인해 주세요. 이 홍보 사이트에는 광고·추적 픽셀·외부 분석 도구를 설치하지 않았어요. 웹 폰트와 이미지는 같은 사이트에서 제공돼요.

4. 보관과 삭제

기기에 저장된 정보는 앱 내 데이터 초기화 기능이나 브라우저의 사이트 데이터 삭제로 지울 수 있어요. 로컬 데이터는 해당 기기에서 지울 때까지 남을 수 있어요. 다른 기기로 자동 동기화하지 않아요.

5. 문의

문의 이메일을 보내면 발신 주소와 문의 내용이 메일 서비스에 전달돼요. 문의 처리를 위해서만 사용하며, 처리 후 불필요한 정보는 삭제해요. 개인정보 열람·정정·삭제 관련 요청도 아래 주소로 보내 주세요.
