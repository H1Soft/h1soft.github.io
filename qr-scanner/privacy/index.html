QR Scanner 개인정보처리방침

시행일: 2026년 8월 24일 · 안내 정정: 2026년 10월 20일 · Windows 버전 안내 추가: 2026년 10월 22일

1. 총칙

본 방침은 H1Soft(이하 "팀")가 제공하는 QR Scanner 앱(이하 "앱")에 적용됩니다. 팀은 「개인정보 보호법」 등 관련 법령을 준수합니다.

2. 처리 원칙 — 온디바이스

QR 인식·생성은 기기에서 처리되며, H1Soft는 QR 내용이나 히스토리를 서버로 수집하지 않습니다. 이용자가 공유·내보내기 또는 QR 링크 열기를 선택하면 지정한 앱이나 사이트로 내용이 전달될 수 있습니다. Android의 SDK 진단정보 처리는 제6항을 참고해 주세요.

3. 수집하는 개인정보

앱은 회원가입이나 로그인을 요구하지 않습니다. H1Soft는 앱 계정용 이름·연락처를 요구하지 않지만, Android의 ML Kit SDK가 처리하는 설치 식별자와 진단정보는 제6항에 안내합니다.

4. 기기 내 저장 정보

아래 정보는 기기 내부에 저장됩니다. 사용자가 직접 공유·내보내기한 사본은 선택한 서비스나 저장 위치에서 관리됩니다.

  • 스캔 기록 — 인식한 QR의 내용과 인식 일시. 앱 내 히스토리에서 개별·전체 삭제 가능
  • 생성 기록 — 생성한 QR의 유형과 입력값, 생성 일시. 동일하게 삭제 가능
  • 앱 설정 — 언어, 화면 모드 등 환경설정 값

5. 권한

앱은 아래 권한을 목적 범위 내에서만 사용합니다. 권한을 거부해도 해당 기능 외 나머지 기능은 사용할 수 있습니다.

  • 카메라 — QR 코드 실시간 인식. 촬영 영상은 저장되지 않으며 인식 즉시 폐기됩니다
  • 사진·미디어 접근 — 갤러리 이미지에서 QR을 인식할 때만 사용. 선택한 이미지 외에는 접근하지 않습니다
  • 저장소 쓰기 — 생성한 QR 이미지를 기기에 저장할 때만 사용

6. 제3자 제공·처리위탁·국외 이전

H1Soft는 QR 내용과 히스토리를 서버로 수집하거나 판매하지 않습니다. Android에서는 Google ML Kit가 다음과 같이 별도의 SDK 지표를 처리하므로 모든 데이터의 외부 전송이 없다고 안내하지 않습니다.

Android: Google ML Kit 데이터 처리

Android 앱은 Google ML Kit를 사용합니다. 이미지·텍스트 등 인식 입력과 결과는 기기에서 처리되며 ML Kit가 이 내용을 Google 서버로 보내지 않습니다. 다만 SDK는 설치 식별자, 기기·앱 정보와 기능 사용·성능·오류 관련 지표를 Google에 전송합니다. 이는 인식 내용과 별개인 진단정보이며, API 유지·개선과 오용 방지 등에 사용됩니다. 전송은 HTTPS로 암호화됩니다.

이 앱은 번들형 바코드 인식 SDK를 사용합니다. 자동 줌을 사용하지 않으므로 자동 줌에 따른 별도의 세션·확대율·좌표 데이터는 해당하지 않습니다.

Google은 여러 국가의 서버에서 정보를 처리합니다. H1Soft가 이 SDK 지표의 처리 국가나 보유기간을 지정하지는 않습니다. 확인한 ML Kit 공개 문서는 이 지표에 적용되는 개별 국가 목록과 고정 보유기간을 명시하지 않습니다. Google의 처리 및 보유 방침은 아래 공식 문서를 참고해 주세요.

이 안내는 Android 버전에 해당하며 iOS의 인식 기능에 ML Kit 사용을 의미하지 않습니다. 앱의 기록 삭제나 앱 삭제가 이미 Google에 전송된 지표의 즉시 삭제를 의미하지는 않습니다. 관련 문의와 권리 행사는 H1Soft 지원 이메일 및 Google 개인정보처리방침의 연락 경로를 이용해 주세요.

7. 파기

히스토리 삭제 시 선택한 앱 내 기록이 삭제되며 팀은 서버 사본을 보관하지 않습니다. 모바일에서는 앱 삭제 시 앱 내부 데이터가 삭제됩니다. 내보내거나 공유한 파일은 별도 사본이므로 저장한 위치에서 삭제해야 합니다. Windows 저장 및 삭제 방법은 아래 버전별 안내를 참고해 주세요.

Windows 버전 안내

Microsoft Store 버전은 기기 내 ZXing 인식 기능을 사용하며 Android ML Kit, 광고 SDK 및 앱 분석 SDK를 포함하지 않습니다. 카메라 스캔은 선택 사항이며 해당 스캔 세션에서 사용자가 사용을 선택한 뒤 시작합니다. 카메라 프레임은 메모리에서 처리합니다. 카메라 없이도 이미지 파일 인식과 QR 만들기를 사용할 수 있습니다.

기록, 언어, 저장한 스타일 및 선택한 로고 사본은 %LOCALAPPDATA%\H1Soft\QRScanner에 저장됩니다. Store 패키지는 Windows가 이 폴더를 별도 경로로 연결할 수 있습니다. 앱은 이 파일을 업로드하지 않습니다. 파일 선택창에서 선택한 파일에 접근하며, PNG·SVG·PDF 내보내기는 사용자가 고른 위치에 저장합니다.

파일 복사는 생성한 로컬 파일의 참조를 Windows 클립보드에 넣고 로컬 클립보드 캐시 사본을 보관합니다. 붙여넣기나 링크 열기는 선택한 앱 또는 웹사이트에 내용을 전달할 수 있습니다. 사용자가 켠 Windows 클립보드 기록·동기화는 Windows 설정에서 관리합니다. 스캔 기록 삭제는 내보낸 파일, 클립보드 기록, 저장한 스타일 및 로고 사본을 삭제하지 않습니다.

Windows 앱 데이터를 모두 삭제하려면 앱을 종료한 뒤 해당 로컬 데이터 폴더를 삭제하거나, 지원되는 경우 Windows의 앱 초기화를 사용해 주세요. 포터블 테스트 버전은 프로그램 폴더를 지워도 로컬 데이터가 남습니다. 내보낸 파일과 클립보드 기록은 필요한 경우 별도로 삭제해 주세요.
