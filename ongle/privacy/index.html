Windows 배포판

온글 Windows 앱은 사용자가 선택한 HWP·HWPX 문서를 컴퓨터에서 열고, 편집·검색·변환합니다. 문서나 개인정보를 개발자 서버에 자동 전송하지 않으며 계정, 광고, 분석 또는 추적 SDK를 사용하지 않습니다.

최근 문서와 읽던 위치, 북마크, 설정, 미리보기·변환 캐시, 복구용 편집 초안과 저장한 서명이 로컬에 보관됩니다. 양식 자동입력을 켜면 직접 입력한 이름·전화번호·생년월일·이메일·주소가 자동입력을 위해 보관됩니다. 앱 데이터는 Windows 사용자별 로컬 앱 데이터 폴더의 H1Soft/Ongle에 저장되며, 언어 선택은 사용자 환경설정에도 저장됩니다. 기록·캐시 정리와 프로필 편집 기능으로 해당 데이터를 관리할 수 있습니다. 캐시 정리만으로 모든 설정·초안·서명이 삭제되는 것은 아닙니다.

PDF·이미지·표·텍스트 내보내기, 원본 저장과 백업은 사용자가 선택한 위치에 파일을 만듭니다. 별도로 저장한 파일은 해당 위치에서 삭제해야 합니다. 앱 제거 후에도 내보낸 파일과 일부 로컬 데이터가 남을 수 있습니다. 휴대용 실행본의 파일을 지우는 것만으로 사용자 데이터가 모두 삭제되지는 않습니다.

낭독은 Windows에 설치된 오프라인 음성을 사용합니다. 선택한 언어의 음성이 없으면 안내하며 클라우드 음성 서비스로 자동 전환하지 않습니다. 재생 정보와 문서 제목이 Windows 미디어 제어 화면에 표시될 수 있습니다.
