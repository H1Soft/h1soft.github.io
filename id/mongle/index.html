Tidak ada server.
Itulah intinya.

Mongle tidak punya server. Tidak perlu daftar atau login, dan tidak ada data yang diunggah. Hasilmu tetap tersimpan di ponselmu.

Pertanyaan umum

Bisakah saya mengikuti tes di web?

Tidak, tes ada di aplikasi. Kemunculan karakter dan kartu hasil dirancang untuk layar ponsel. Instal dan selesai dalam satu menit.

Apakah saya perlu akun?

Tidak. Instal lalu mulai. Kami tidak meminta email atau nomor telepon.

Di mana data saya disimpan?

Hanya di ponselmu. Mongle tidak punya server, jadi kami pun tidak bisa melihat hasilmu.

Apakah hasil saya hilang saat ganti ponsel?

Ekspor data menjadi file di Pengaturan, lalu impor di perangkat baru. Karena tidak ada server, tidak ada pencadangan otomatis. Ekspor sebelum menghapus data ponsel lama.

Apakah tes ini akurat secara ilmiah?

Tidak. Mongle adalah hiburan, bukan penilaian psikologis. Nikmati dengan santai.

Apakah aplikasinya tersedia dalam bahasa Indonesia?

Ya. Pilih bahasa Indonesia atau bahasa lain yang didukung di Pengaturan. Aplikasi menyediakan 11 varian bahasa.
