Mongle · Privasi

Mongle berjalan tanpa akun maupun server iklan atau analitik. Pengembang tidak mengumpulkan atau menerima data pribadi dari aplikasi. Hasil, nama panggilan, teman, pengaturan, dan progres koleksi disimpan di perangkat.

Kamera hanya dipakai saat memindai QR teman. Video tidak disimpan atau dikirim. Izin menambahkan foto hanya dipakai untuk menyimpan kartu hasil ke Foto.

Kode, gambar kartu, dan cadangan JSON hanya diteruskan ke aplikasi pilihan saat kamu membagikannya. Jika mengirim email bantuan, alamat dan pesanmu digunakan untuk membalas. Jangan kirim informasi sensitif.

Atur ulang data di Pengaturan atau hapus aplikasi. Hapus file ekspor dan foto tersimpan secara terpisah. Sistem operasi dapat menyertakan data aplikasi dalam cadangan perangkat sesuai pengaturanmu.

Situs ini tidak memakai skrip iklan atau analitik. GitHub Pages dapat memproses alamat IP dan informasi koneksi untuk menyediakan dan mengamankan situs. Lihat pernyataan privasi GitHub.
