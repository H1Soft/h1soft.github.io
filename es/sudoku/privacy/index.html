Privacidad

2026-09-08

Sudoku Voyage no recopila ni transmite datos personales al desarrollador. El progreso, los ajustes y las estadísticas permanecen en tu dispositivo. Solo compartes copias de seguridad y postales cuando eliges exportarlas. Las notificaciones se programan localmente. Si escribes a soporte, recibimos tu correo y mensaje únicamente para responder. GitHub Pages aloja este sitio y puede procesar registros técnicos de acceso. Si cambia el tratamiento de datos, actualizaremos esta política y la declaración del App Store antes de publicar el cambio.
