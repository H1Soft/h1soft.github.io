Privacidad

Mongle funciona sin cuenta ni servidores de publicidad o análisis. El desarrollador no recoge ni recibe datos personales de la app. Los resultados, apodos, amigos, ajustes y progreso se guardan en tu dispositivo.

La cámara solo se usa para escanear el QR de un amigo. No se guarda ni envía vídeo. El permiso para añadir fotos solo sirve para guardar una tarjeta en Fotos.

Los códigos, las tarjetas y las copias JSON se envían a la app elegida únicamente cuando los compartes. Si escribes a soporte, usamos tu dirección y mensaje para responder. No envíes información sensible.

Restablece los datos en Ajustes o elimina la app. Borra por separado los archivos exportados y las fotos guardadas. El sistema operativo puede incluir los datos en las copias del dispositivo según tus ajustes.

Este sitio no incluye scripts de publicidad ni análisis. GitHub Pages puede tratar direcciones IP y datos de conexión para servir y proteger el sitio. Consulta la declaración de privacidad de GitHub.
